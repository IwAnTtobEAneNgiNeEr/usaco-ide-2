# App hiện tại

USACO IDE 2.0 là ứng dụng Electron local-first tại `E:\usaco-ide-2`, dùng Express local judge và C++17. Đây là nguồn sự thật duy nhất cho kế hoạch C++.

# Flow C++ hoàn chỉnh

Import → Solve → Verify → Diagnose → Understand → Build → Apply

# Những gì đã hoàn thành

OJ workspace giữ code lời giải theo từng bài; Judge chạy C++ thật; module thuật toán có source, verifier và lịch sử kiểm chứng riêng.

# Update hiện tại — Unified C++ Workspace

Module mở trong cùng Activity Workspace với CodeMirror, file tab, topbar, phím tắt và panel Verify/diagnose/history. Không còn modal hoặc textarea module. Đóng module quay lại đúng context OJ và không thay đổi source OJ.

# Các update C++ tiếp theo

1. Problem Intake & Test Intelligence
2. Algorithm Classification & Understanding
3. C++ Multi-file Engineering
4. Applied C++ Projects
5. C++ Product Consolidation

# Điều kiện hoàn thiện C++ trước fullstack

Mọi luồng C++ phải dùng editor thật, verifier thật, chẩn đoán rõ ràng, lưu/reload/restart đúng và có test backend/frontend xanh. Không bắt đầu fullstack trước khi các điều kiện này đạt.

# Non-goals hiện tại

Không thêm feature fullstack, không tạo workspace/editor thứ hai, không redesign ngoài luồng C++ hiện hữu.
